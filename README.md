# Swale CLI

`swale` is the command line interface to [Swale](https://swale.io) — create and run workflows, and manage projects, task definitions and secrets from a terminal.

This repository publishes the CLI's releases and its container image, `swaleio/swale-cli`. The CLI is built elsewhere; releases are all that is hosted here.

- **Install it, or run it in a container:** [Install the CLI](https://docs.swale.io/reference/install-cli) has the installers for every platform, the steps for a binary taken from the [releases](../../releases), and how to run the `swaleio/swale-cli` image.
- **Verify a release:** [Verifying a download](https://docs.swale.io/reference/install-cli#verifying-a-download) and [Platform signatures](https://docs.swale.io/reference/install-cli#platform-signatures).
- **Use it:** the [CLI reference](https://docs.swale.io/reference/cli-reference) lists every command and option.
